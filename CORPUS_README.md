# CA HCAI Chargemaster Corpus — Ingest Output

Generated by `ingest_hcai.py` from CA HCAI (OSHPD) hospital chargemaster
disclosures 2014–2025. One row per (hospital × sheet × code × charge column).

## Files

| File | Purpose |
|---|---|
| `cdm_YYYY.parquet` × 12 | Per-year typed table (snappy-compressed) |
| `cdm_all.parquet` | Concatenated master, 56.5M rows |
| `ingest_log.csv` | One row per (file, sheet) with header_row, detected columns, n_matches, status |
| `ingest_errors.csv` | Files or sheets that failed to parse |
| `coverage_report.md` | Per-year row/hospital counts + sheet-level status distribution |

## Corpus summary

- **Total rows**: 56,544,334
- **Unique OSHPD facility IDs**: 439 (across all years)
- **Code types captured**: CPT, HCPCS, REVCODE, DRG, NDC (ICD-10-PCS supported but rare in CDMs)
- **Years**: 2014–2025

## Schema (per row)

| Column | Type | Notes |
|---|---|---|
| `year` | int | Disclosure year |
| `oshpd_id` | str | 9-digit CA HCAI facility ID; may be null for ~15% of 2024–2025 files where filename lacks the prefix |
| `hospital_folder` | str | Raw folder name (not canonicalized) |
| `file_source` | str | Relative path under `/data0/hcai-chargemasters/` |
| `sheet_name` | str | Sheet within the xlsx/xls file |
| `header_row` | int | Row index detected as the header (audit trail) |
| `code_type` | str | CPT \| HCPCS \| REVCODE \| DRG \| NDC \| ICD10PCS |
| `procedure_code` | str | Normalized (uppercase, alnum-only) |
| `description` | str | Line description from the CDM |
| `charge_column` | str | Which column the charge came from (e.g., `Gross Charge`, `I/P Charge`, `2024 Price`) |
| `charge_raw` | str | Original cell string (preserved for audit) |
| `charge` | float | Parsed numeric; `NaN` if unparseable |
| `setting` | str | IP \| OP \| ER \| OR \| SB \| ALL (derived from `charge_column` name) |
| `unit` | str | Unit of measure if disclosed (e.g., `each`, `day`, `dose`) |
| `ingest_version` | str | Ingest run tag (`2026-04-23-v1`) |

## How to use

```python
import pandas as pd
df = pd.read_parquet('/data0/hcai-chargemasters/ingest/cdm_all.parquet')

# Target-CPT ED + OB delivery
targets = ['99281','99282','99283','99284','99285','99291','99292',
           '59400','59410','59510','59514']
ed_ob = df[(df['code_type']=='CPT') & df['procedure_code'].isin(targets)]

# Delivery DRGs
drg = df[(df['code_type']=='DRG') & df['procedure_code'].isin(['765','766','767','768'])]

# ED revenue codes (most hospitals report at revenue-code level)
ed_rev = df[(df['code_type']=='REVCODE') & df['procedure_code'].isin(['0450','0451','450','451'])]
```

## Known limitations

1. **~70K unique CPT codes** in the corpus exceeds the real AMA CPT namespace (~10K). The inflation comes from internal 5-digit hospital billing codes that pass the `^\d{5}$` regex. A canonical AMA CPT + CMS HCPCS filter is the natural next step; downstream analyses should apply that filter to target CPTs explicitly.
2. **~15% of 2024–2025 files lack OSHPD ID** in the filename. Those rows have `oshpd_id = None` and won't join to a facility-level lookup without hospital-name canonicalization.
3. **Hospital folder names are not canonicalized** across years — `Kaiser Foundation Hospital - Fremont` vs `KAISER FEM — FREMONT`. Use OSHPD ID when joining across years; fall back to fuzzy name matching only when ID is missing.
4. **Charges extracted verbatim**. No outlier removal, no winsorization. Extreme values (negative, >$1B) exist in the source and should be cleaned at analysis time, not in the corpus.
5. **Some hospitals report no CPT/HCPCS at all** — rehab, behavioral health, LTAC, or Kaiser-style hospitals use only internal codes. They appear in the corpus via revenue codes and NDCs only. This is a feature of CA HCAI disclosures, not a bug in the ingest.

## Reproducing

```bash
cd /home/saptpurk/california_chargemasters
.venv/bin/python ingest_hcai.py \
    --base /data0/hcai-chargemasters \
    --out  /data0/hcai-chargemasters/ingest \
    --workers 16
```

Runtime: ~15 min on 16 cores for the full 2014–2025 run (4,372 CDM files).

Requirements pinned in `requirements.txt` (pandas 2.2+, openpyxl, xlrd 2.0.2, pyarrow, tqdm).
