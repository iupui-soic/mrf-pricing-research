## 1. CA HCAI Chargemaster Corpus

Generated by `ingest_hcai.py` from CA HCAI (OSHPD) hospital chargemaster
disclosures 2014–2025. One row per (hospital × sheet × code × charge column).

### Files

| File | Purpose |
|---|---|
| `cdm_YYYY.parquet` × 12 | Per-year typed table (snappy-compressed) |
| `cdm_all.parquet` | Concatenated master, 56.5 M rows |
| `ingest_log.csv` | One row per (file, sheet) with header_row, detected columns, n_matches, status |
| `ingest_errors.csv` | Files or sheets that failed to parse |
| `coverage_report.md` | Per-year row/hospital counts + sheet-level status distribution |
| `cache_census_zip_2024.csv` | ACS 5-year CA ZIP-level Census variables (cached) |
| `ca_deaths_zip_2019-2024.csv` | CA all-cause mortality at ZIP × year |

### Summary

- **Total rows**: 56,544,334
- **Unique OSHPD facility IDs**: 439 (across all years)
- **Code types captured**: CPT, HCPCS, REVCODE, DRG, NDC (ICD-10-PCS supported but rare)
- **Years**: 2014–2025

### Schema (per row)

| Column | Type | Notes |
|---|---|---|
| `year` | int | Disclosure year |
| `oshpd_id` | str | 9-digit CA HCAI facility ID; null for ~15% of 2024–2025 files where filename lacks the prefix |
| `hospital_folder` | str | Raw folder name (not canonicalized) |
| `file_source` | str | Relative path under `/data0/mrf-pricing-research/hcai-chargemasters/` |
| `sheet_name` | str | Sheet within the xlsx/xls file |
| `header_row` | int | Row index detected as the header (audit trail) |
| `code_type` | str | CPT \| HCPCS \| REVCODE \| DRG \| NDC \| ICD10PCS |
| `procedure_code` | str | Normalized (uppercase, alnum-only) |
| `description` | str | Line description from the CDM |
| `charge_column` | str | Which column the charge came from (e.g., `Gross Charge`, `I/P Charge`, `2024 Price`) |
| `charge_raw` | str | Original cell string (preserved for audit) |
| `charge` | float | Parsed numeric; `NaN` if unparseable |
| `setting` | str | IP \| OP \| ER \| OR \| SB \| ALL (derived from `charge_column` name) |
| `unit` | str | Unit of measure if disclosed (e.g., `each`, `day`, `dose`) |
| `ingest_version` | str | Ingest run tag (`2026-04-23-v1`) |

### How to use

```python
import pandas as pd
df = pd.read_parquet('/data0/mrf-pricing-research/hcai-chargemasters/ingest/cdm_all.parquet')

# Target-CPT ED + OB delivery
targets = ['99281','99282','99283','99284','99285','99291','99292',
           '59400','59410','59510','59514']
ed_ob = df[(df['code_type']=='CPT') & df['procedure_code'].isin(targets)]
```

### Known limitations

1. **~70 K unique CPT codes** in the corpus exceeds the real AMA CPT namespace (~10 K). The inflation comes from internal 5-digit hospital billing codes that pass `^\d{5}$`. Apply an AMA reference-list filter downstream.
2. **~15% of 2024–2025 files lack OSHPD ID** in the filename; those rows have `oshpd_id = None`.
3. **Hospital folder names are not canonicalized** across years. Use OSHPD ID for cross-year joins; fall back to fuzzy name matching only when ID is missing.
4. **Charges extracted verbatim** — no outlier removal, no winsorization. Extreme values exist in the source.
5. **Some hospitals report no CPT/HCPCS** — Kaiser, rehab, behavioral health, LTAC use only internal codes. They appear only via revenue codes and NDCs.

## 4. Hospital Identity Crosswalk

Built by `build_crosswalk.py`. Single source of truth for joining the
CA chargemaster, federal MRF, and Medicare benchmark corpora to each
other and to external datasets (Census, mortality, NPPES).

### Files

| File | Purpose |
|---|---|
| `/data0/mrf-pricing-research/crosswalk/facilities_crosswalk.parquet` | Master crosswalk, 528 × 18 |
| `/data0/mrf-pricing-research/crosswalk/facilities_crosswalk.csv` | CSV mirror (for spot inspection) |
| `/data0/mrf-pricing-research/crosswalk/crosswalk_coverage.md` | Per-field coverage breakdown with provenance |
| `/data0/mrf-pricing-research/crosswalk/ccn_to_npi.csv` | NPI extracted from MRF metadata `type_2_npi` |
| `/data0/mrf-pricing-research/crosswalk/ccn_to_npi_nppes.csv` | NPI from NPPES Registry API fallback |

### Schema (per row)

| Column | Source | Coverage |
|---|---|---|
| `ccn` | CMS POS | 100% |
| `oshpd_id` | HCAI facilities + 11 hand-mapped renames | 100% of state-licensable CA |
| `ein` | CMS-mandated MRF filename `<EIN>_<hospital>_standardcharges.{csv,json}` | 381/528 (72%); 83% of real MRFs |
| `ein_source` | `url_filename` | — |
| `npi` | MRF metadata `type_2_npi` + NPPES NPI Registry API fallback | 505/528 (96%); 98% of real MRFs |
| `npi_source` | `mrf_metadata` \| `nppes:taxonomy:<type>` \| `nppes:taxonomy+name:<type>` \| `nppes:zip+name` \| `nppes:state+name` | — |
| `in_facility_id` | Indiana SDH licensure | 0% — IN SDH publishes only PDF; analysis keys on CCN for IN |
| `name`, `address`, `city`, `state`, `zip`, `county` | CMS POS | 100% |
| `hospital_type`, `ownership`, `has_ed` | CMS POS | 100% |
| `oshpd_match_score` | 0.0–1.0 fuzzy similarity (CA only) | — |
| `oshpd_match_method` | `exact_zip+name` \| `zip_only_fuzzy` \| `name_only_fuzzy` \| `manual_override` \| `n/a (federal)` \| `n/a (no HCAI counterpart)` | — |

### EIN — note on scope

EIN is **not in the CMS v3.0 MRF metadata schema**. CMS uses EIN only in
the mandated filename convention. The pipeline extracts EIN from those
filenames (381 hospitals) but does not chase coverage further: EIN is an
optional join key, primarily useful for IRS Form 990 enrichment of
nonprofit hospitals, and is not on the critical path for the analytic
pipeline (which keys on CCN and NPI throughout). Aggregator-portal-served
hospitals (PARA HCFS, hospital-price-index, Box, Craneware) typically
strip the EIN from the URL — those gaps are residual and accepted.

### OSHPD match-method distribution (CA)

- `exact_zip+name` (≥0.9 sim): 306
- `zip_only_fuzzy` (0.65–0.9 sim): 37
- `name_only_fuzzy` (≥0.85, cross-ZIP): 9
- `manual_override` (hand-mapped renames): 11
- `n/a (federal)` (VA/DoD, exempt from HCAI): 13
- `n/a (no HCAI counterpart)` (closed / never licensed): 2
- `unmatched`: **0**

### Residual gaps and what would close them

- **EIN (54 of 458 real MRFs)**: dominated by for-profit hospitals served via aggregator portals (PARA HCFS, hospital-price-index, Box). CMS does not publish CCN→EIN; IRS Form 990 only covers tax-exempt entities. Closing requires commercial data (Definitive Healthcare), SEC EDGAR (publicly-traded subset), or state corporate filings.
- **NPI (56 of 458 real MRFs)**: hospitals where NPPES legal name diverges from CMS POS name. Closing requires the **NPPES bulk dissemination file** (~10 GB monthly) for ZIP-keyed exact match.
- **Indiana SDH facility ID (150 of 150)**: IN SDH publishes only a PDF licensure listing, no public CSV. Not blocking — the analytic pipeline keys on CCN for IN throughout.
